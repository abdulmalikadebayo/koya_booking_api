# Koya Booking API - Web page

The booking page: see the available slots, book one, and see the confirmation. Built with Vite, React 19, TypeScript, Tailwind v4 and the [BoardUI](https://www.boardui.com) component library.

## Run

```bash
npm install
cp .env.example .env.local
npm run dev        # http://localhost:5173
```

| Variable | Meaning |
|---|---|
| `VITE_API_URL` | Base URL of the booking API |
| `VITE_API_KEY` | The key the page sends in `X-API-Key`. It ends up in the page's JavaScript, so use a key separate from the one you give anyone else. |

The API must allow this page's origin in its `CORS_ALLOWED_ORIGINS`.

## Build

```bash
npm run build      # type-checks, then writes dist/
```

## Where things are

- `src/api.ts` - API client. Booking requests send an `Idempotency-Key`, so a double click books once.
- `src/booking/` - the slot list, booking form and confirmation.
- `src/components/` - BoardUI components, generated by `npx boardui@latest add`.
